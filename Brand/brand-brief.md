# DepScout Brand Brief

## Brand

**Name:** DepScout

**English slogan:** Install decisions for coding agents.

**Russian positioning:** Проверка зависимостей перед установкой агентом.

## One-Liner

DepScout checks npm packages, PyPI packages, and GitHub repositories before a coding agent installs a dependency, then returns a compact `safe`, `caution`, or `block` verdict.

## What DepScout Does

DepScout is not a legal compliance product and not a full enterprise security scanner. It is a developer-hygiene API for the exact moment before an agent runs `npm install`, `pnpm add`, `pip install`, or pulls code from GitHub.

Signals:

- license clarity
- last release or repository activity
- maintainer/owner surface
- deprecation or yanked state
- known public vulnerability records when available
- install scripts and dependency footprint
- typosquat or slopsquat suspicion

## Target Users

- coding agent platforms
- AI IDEs and repo assistants
- CI bots that review dependency changes
- developers who let agents modify dependencies
- small teams that want a cheap package-risk check without enterprise onboarding

## Core Promise

DepScout gives agents one install decision before a dependency enters the repo.

## Visual Style

- premium developer-tool SaaS
- quiet, technical, fast to scan
- deep navy, signal blue, and mint gradient
- selected logo direction: Variant A from the Image 2.0 concept sheet
- shield + package cube + radar sweep as the primary mark
- no legal/compliance tone, no crypto-trading cliches

## Landing Page Direction

Suggested hero copy:

**DepScout**

Install decisions for coding agents.

Check package risk before npm, pip, or repo install. DepScout returns a compact verdict agents can show before changing dependencies.

Primary CTA:

Check a package
