## Product Meaning

DepScout is a package-risk API for the moment before a coding agent adds a dependency. It checks public metadata for npm packages, PyPI packages, and GitHub repositories, then returns a compact install verdict: `safe`, `caution`, or `block`.

DepScout is developer hygiene, not legal compliance. The product helps agents and developers avoid obvious dependency mistakes before running `npm install`, `pnpm add`, `pip install`, or pulling a GitHub repo.

## Who Pays

- AI IDEs and coding-agent platforms that need dependency checks before automated installs.
- Repo assistants and CI bots that review dependency changes.
- Developer teams that want a cheap, fast pre-install risk signal without enterprise security onboarding.
