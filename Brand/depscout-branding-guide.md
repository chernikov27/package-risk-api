# DepScout Branding Guide

This folder contains the selected DepScout brand direction for the landing page.

## Selected Logo

Use **Variant A** from `depscout-branding-guide.png`.

The selected mark combines:

- shield
- package cube
- radar sweep
- cyan-to-mint gradient

This is the right direction because DepScout is a pre-install package-risk API: it protects the repository, scans a dependency target, and returns a clear install decision.

## Brand Assets

- `depscout-branding-guide.png` - Image 2.0 concept sheet with the three generated logo options.
- `depscout-logo-source.svg` - clean SVG source for the selected Variant A direction.
- `depscout-brand-system.svg` - compact brand board with colors and voice notes.
- `depscout-slogan.md` - English and Russian slogan, positioning, audience, and landing-page copy notes.

## Color Palette

- Deep navy: `#071226`
- Panel navy: `#0b1730`
- Signal blue: `#66e6ff`
- Mint: `#35f2b0`
- Text white: `#f8fbff`
- Muted text: `#c6d3e6`

## Wordmark

Use the exact product name:

**DepScout**

Do not write `Dep Scout`, `Depscout`, or `Dep-Scout`.

## Slogan

**Install decisions for coding agents.**

Use this as the core English slogan on the landing page.

Russian positioning:

**Проверка зависимостей перед установкой агентом.**
